## 🌌 Overview

The Warhammer 40K Trainer Companion Hub began as a personal notebook — a place to record which toggles mattered, which settings caused friction, and how a companion utility could be made more intuitive for players who want to explore the vast sandbox that is Warhammer 40K on PC. Over time, that notebook grew into the structured repository you are reading right now.

The core philosophy is simple: **a trainer should feel like a trusted advisor, not a mystery box.** Every section of this documentation is written to reduce guesswork. Whether you are running Windows 11 with the latest feature update or holding onto a trusty Windows 10 build from years past, the guidance here is designed to meet you where you are.

This repository does not host the companion utility itself. Instead, it provides:

- A structured **setup guide** for Windows environments.
- A **troubleshooting appendix** covering the most common friction points.
- A **module reference** describing each toggle category conceptually.
- A **roadmap** that reflects the direction of the 2026 release cycle.
- A **community-oriented FAQ** answering the questions that appear most often.

The tone is intentionally conversational. You will not find walls of jargon here. You will find explanations that assume you are a capable adult who simply wants things to work.

## ✨ Feature Highlights

### 🎛️ Toggle Architecture

The companion utility organizes its capabilities into **modules**, each representing a broad category of adjustments. Modules are grouped by theme rather than by individual toggle, which keeps the interface from becoming a wall of switches. Think of it as a well-organized armory: every weapon has its rack, and every rack has its label.

### 🖥️ Responsive Interface

The interface adapts fluidly to different window sizes, resolutions, and display scaling settings. Whether you are on a 13-inch laptop screen at 125% scaling or an ultrawide monitor at 100%, the layout remains legible and the controls remain reachable. This responsiveness is not an afterthought — it is a foundational design decision documented throughout this repository.

### ☎️ 24/7 Customer Support

Support is available around the clock, every day of the year. The support team maintains a rotating schedule so that no timezone is left in the dark. Response times are documented in the FAQ section below. ### 🔄 Automatic Profile Snapshots

Configuration profiles can be saved as snapshots. Each snapshot records the state of every module at a given moment, allowing you to return to a known-good configuration after experimentation. Snapshots are stored locally and are never uploaded anywhere.

## 🎨 Responsive Interface Philosophy

A responsive interface is more than a buzzword. It is a promise that the tool will not fight you when your environment changes. The companion utility was designed with three principles in mind:

1. **Legibility first.** Text scales cleanly. Nothing is rendered below a readable minimum size.
2. **Reachability second.** Controls never migrate to off-screen positions when the window is resized.
3. **Predictability third.** The layout does not rearrange itself arbitrarily. Elements stay where you left them.

These principles are documented because they inform every design decision in the 2026 line. If a future change would violate one of them, it is reconsidered.

## 🌍 Multilingual Support

Localization is treated as a first-class concern. The repository includes notes on how translations are structured, how they are reviewed, and how updates flow into releases. The following table summarizes the localization pipeline:

| Stage | Description | Owner |
| --- | --- | --- |
| Extraction | Strings are extracted from source | Maintainers |
| Translation | Strings are translated by native speakers | Community translators |
| Review | Translations are reviewed for accuracy and tone | Reviewers |
| Merge | Approved translations enter the next release | Maintainers |
| Verification | Final build is checked for missing or broken strings | QA |

This pipeline exists so that no language is left half-finished. A partially translated language is worse than no translation at all, because it creates a confusing experience for the user.

## 🧱 Module Breakdown

Modules are the building blocks of the companion utility. Each module groups related adjustments under a single heading. The following list describes each module conceptually — without detailing individual toggles, which are covered in the in-app documentation.

- **Campaign Module**: Adjustments relevant to narrative progression and mission pacing.
- **Skirmish Module**: Adjustments relevant to standalone battles and custom scenarios.
- **Economy Module**: Adjustments relevant to resource flow and progression pacing.
- **Unit Module**: Adjustments relevant to unit behavior and availability.
- **Interface Module**: Adjustments relevant to on-screen information density.
- **Diagnostics Module**: Tools for inspecting configuration health.

Each module can be enabled or disabled independently. Disabling a module removes its controls from the interface, reducing clutter for users who do not need them.
